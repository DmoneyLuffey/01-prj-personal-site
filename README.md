# Damani Ward Portfolio Website

A beginner-friendly single-page personal portfolio built with HTML, CSS, and JavaScript.

This project showcases:
- Personal bio and hobbies
- Technical skills
- Featured projects with live links
- Social and contact links
- Simple interactive JavaScript features (scroll effect and music toggle)

## Live Project Goal

The goal of this website is to present who I am, what I can build, and where people can contact me.

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- Font Awesome (icons)
- Devicon (technology icons)
- Google Fonts (Orbitron)

## Project Structure

```text
01-prj-personal-site/
|- index.html         # Main page structure and content
|- style.css          # All styling, layout, and visual theme
|- script.js          # Interactive behavior
|- README.md          # Project documentation
|- img/               # Images used on the page
|- audio/             # Audio files used by the music player
```

## Sections in the Website

The page is divided into these sections:

1. Hero
2. Bio
3. Hobbies
4. Skills
5. Projects
6. Social Media
7. Contact

Navigation links at the top jump to each section by id.

## Current Features

### Visual Design

- Futuristic color palette with cyan highlights
- Card-style sections with consistent spacing
- Icon hover effects and project card hover animation
- Fixed top navigation with scroll transparency change

### JavaScript Features

- Navigation bar style changes when the page is scrolled
- Background music toggle button (mute and unmute)
- Music playback starts after the user's first click

## Accessibility Improvements

The site includes key accessibility basics:

- Document title in the head
- Main content wrapped in a main landmark
- Icon-only links include aria-label text
- Decorative icons marked with aria-hidden
- Music toggle button includes an aria-label
